# 🎬 CineLog

Um sistema de gerenciamento de filmes inspirado no Letterboxd, desenvolvido para praticar conceitos de desenvolvimento de software desde os fundamentos até uma aplicação Full Stack.

## 📖 Sobre o projeto

O CineLog começou como uma aplicação de terminal em Python e está sendo desenvolvido em etapas, acompanhando minha evolução como desenvolvedor.

O objetivo é transformar um simples CRUD em uma aplicação completa com interface web e banco de dados.

🔄 CRUD

O CineLog já possui as principais operações de um CRUD:

Operação	Método	Status
Criar filme	POST	✅
Listar filmes	GET	✅
Editar filme	PUT	✅
Excluir filme	DELETE	✅

Os dados são persistidos em um arquivo JSON, permitindo que os filmes continuem salvos mesmo após o encerramento da aplicação.

🛠️ Backend

O backend é desenvolvido em Python e atualmente utiliza JSON como forma de persistência.

A API é responsável por:

Receber requisições do frontend
Processar os dados dos filmes
Realizar operações CRUD
Salvar e carregar os dados do arquivo JSON
