================================
1. VISÃO DO PROJETO
================================

CineLog é uma plataforma inspirada em sites como Letterboxd, mas com identidade própria.

Objetivo:
- Catalogar filmes, séries e futuramente animes.
- Exibir páginas individuais bem alimentadas.
- Permitir avaliação, favoritos, watchlist e reviews.
- Futuramente possuir sistema de usuário e perfil.
- Ter uma interface moderna, viva, fluida e marcante.

Identidade visual atual:
- Fundo escuro.
- Laranja forte como cor principal de ação/destaque.
- Vermelho forte pode aparecer como cor de destaque.
- Roxo pode ser usado como cor criativa/secundária.
- Cards com transparência e bordas sutis.
- Visual cinematográfico, moderno e convidativo.
- Evitar copiar diretamente a identidade visual do Letterboxd.

4. BACKEND
================================

4.1 app.py
-----------

Responsabilidade:
- Criar a aplicação Flask.
- Configurar CORS.
- Definir as rotas da API.
- Transformar linhas do SQLite em objetos JSON.
- Entregar os dados para o React.

Função importante:

transformar_filme(filme)

Converte a tupla retornada pelo SQLite em um objeto com nomes de propriedades.

Campos atuais enviados pela API:
- id
- tmdb_id
- titulo
- titulo_original
- tipo
- sinopse
- data_lancamento
- nota_tmdb
- popularidade
- idioma
- poster_path
- generos
- diretor
- elenco

OBS:
As novas colunas generos, diretor e elenco precisam estar incluídas na transformação quando necessário.


4.2 banco.py
------------

Responsabilidade:
- Conectar ao SQLite.
- Criar a tabela.
- Inserir conteúdos.
- Buscar conteúdos.
- Ordenar conteúdos.
- Buscar filme por TMDB ID.
- Atualizar a estrutura do banco quando novas colunas são necessárias.

Banco:

cinelog.db

Tabela principal:

conteudos


Campos planejados/atuais:

popularidade        REAL

Funções importantes:
- conectar()
- criar_tabela()
- atualizar_tabela()
- inserir_conteudo()
- listar_filmes()
- buscar_filme_por_id()
- buscar_filmes()

IMPORTANTE:
Ao adicionar uma nova coluna ao banco, atualizar:
1. banco.py
2. importação dos dados
3. transformar_filme() no app.py
4. frontend que irá consumir o dado


4.3 importar_filmes.py
----------------------

Responsabilidade:
- Consultar a API do TMDB.
- Pegar dados dos filmes.
- Transformar os dados no formato usado pelo CineLog.
- Inserir no SQLite.

Atualmente importa filmes populares.

Token do TMDB:
- Fica no .env.
- Nunca colocar o token diretamente no código ou publicar no GitHub.

5. API ATUAL
================================

GET /api/filmes
→ Lista filmes.

GET /api/filmes/buscar?q=TERMO
→ Busca filmes pelo título.

GET /api/filmes/avaliados
→ Lista filmes ordenados pela nota.

GET /api/filmes/populares
→ Lista filmes ordenados pela popularidade.

GET /api/filmes/{tmdb_id}
→ Retorna um filme específico.


Exemplo:

/api/filmes/634649

Retorna os dados do Spider-Man: No Way Home quando ele existe no banco.

20. COMO PENSAR AO IMPLEMENTAR
================================

NUNCA começar imediatamente pelo JSX.

Antes de programar uma funcionalidade, responder:

1. O que estou criando?

2. De onde vem o dado?

3. O dado precisa ser salvo?

4. Se precisa ser salvo:
   → SQLite?
   → localStorage?
   → futuramente conta do usuário?

5. Qual tabela/coluna precisa existir?

6. O backend precisa de uma nova função?

7. O Flask precisa de uma nova rota?

8. O JSON da API precisa mudar?

9. Qual componente React vai receber o dado?

10. Preciso de useState?

11. Preciso de useEffect?

12. Qual JSX vai mostrar o dado?

13. Qual CSS vai controlar a aparência?

14. Preciso testar:
   → banco
   → API
   → React
   → interface?

http://127.0.0.1:5000/api/filmes/avaliados

http://127.0.0.1:5000/api/filmes/634649


Se a API funcionar mas o React não:
→ problema provavelmente está no frontend.

Se o React pedir dados mas a API retornar 404:
→ problema provavelmente está no backend/rota.

Se a API não possuir o dado:
→ verificar banco/importação/TMDB.

23. ERROS IMPORTANTES JÁ ENCONTRADOS
================================

1. Flask retornava 404 para filme específico.
   Causa: backend que estava executando não possuía a rota nova.
   Solução: reiniciar o Flask com o app atualizado.

2. Invalid hook call no React.
   Causa encontrada no contexto do projeto: conflito/duplicidade de instalação do React.
   Verificação:
   npm ls react react-dom react-router-dom

   Atualmente:
   React 19.2.8
   React DOM 19.2.8
   React Router DOM 7.18.2


3. ImportError de atualizar_conteudo.
   Causa: a função existente era atualizar_tabela(), não atualizar_conteudo().
   Regra:
   Não importar função que não existe.


4. NameError:
   return filmes dentro de atualizar_tabela().
   Causa: filmes não existia dentro daquela função.
   Solução: remover return filmes.


5. TypeError:
   'NoneType' object is not iterable.
   Causa: alguma função de banco estava retornando None em vez de lista.


6. Problemas com comandos PowerShell.
   Atenção:
   Não misturar comandos de PowerShell com sintaxe de CMD.

================================
26. REGRA DE OURO DO PROJETO
================================

O CineLog não deve ser desenvolvido tentando lembrar tudo de cabeça.

Antes de implementar qualquer coisa:

1. Consultar este mapa.
2. Definir o fluxo do dado.
3. Alterar uma camada por vez.
4. Testar a camada.
5. Só então passar para a próxima.
6. Atualizar este arquivo quando a arquitetura mudar.

O objetivo não é apenas fazer o CineLog funcionar.

O objetivo é aprender a construir um sistema completo entendendo
POR QUE cada parte existe e COMO as partes se comunicam.
