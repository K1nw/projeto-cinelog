# 🎬 CineLog

Um sistema de gerenciamento de filmes inspirado no Letterboxd, desenvolvido para praticar conceitos de desenvolvimento de software desde os fundamentos até uma aplicação Full Stack.

## 📖 Sobre o projeto

O CineLog começou como uma aplicação de terminal em Python e está sendo desenvolvido em etapas, acompanhando minha evolução como desenvolvedor.

O objetivo é transformar um simples CRUD em uma aplicação completa com interface web e banco de dados.

## ✨ Funcionalidades

- Adicionar filmes
- Listar filmes
- Avaliar filmes (1 a 10)
- Escrever reviews
- Persistência de dados com JSON
